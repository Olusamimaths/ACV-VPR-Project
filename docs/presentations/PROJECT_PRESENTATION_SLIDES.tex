  \vspace{0.5em}
  \begin{block}{Problem}
    \small
    We want a robot to recognize its location at night using a daytime map. This is hard because large illumination changes make many daytime-trained descriptors unstable at night.
  \end{block}
\end{frame}

\begin{frame}{2. Gap and Hypothesis}
  \begin{block}{Gap in existing work}
    \small
    Many VPR papers report strong benchmark performance, but it is still unclear which descriptors \textbf{transfer best to our specific setting}: day-to-night localization, training-free evaluation, and a small campus deployment scenario.
  \end{block}

  \vspace{0.5em}
  \begin{block}{Research question}
    \small
    If we keep the pipeline simple and avoid retraining, which descriptor gives the most reliable nocturnal place recognition on both a controlled benchmark and our own campus dataset?
  \end{block}

  \vspace{0.5em}
  \begin{block}{Hypothesis}
    \small
    \textbf{Descriptor choice is the dominant factor} in our current nocturnal VPR setup. We expect modern VPR descriptors to outperform older or more generic baselines on both GardensPoint and the strict campus dataset.
  \end{block}
\end{frame}

\begin{frame}{3. Related Work and What We Tried}
  \begin{columns}[T,totalwidth=\textwidth]
    \column{0.48\textwidth}
      \begin{block}{Descriptors evaluated}
        \small
        \begin{itemize}
          \item \textbf{Older / generic}: SAD, AlexNet, NetVLAD
          \item \textbf{Local + global}: PatchNetVLAD
          \item \textbf{Modern VPR descriptors}: CosPlace, EigenPlaces, SALAD, SelaVPR++
          \item \textbf{Specialized spiking model}: VPRTempo
        \end{itemize}
      \end{block}

      \begin{block}{What these are}
        \small
        CosPlace / EigenPlaces learn strong global place descriptors. SALAD improves descriptor aggregation with DINOv2 features. SelaVPR++ adapts foundation models for efficient place recognition. VPRTempo is a fast temporally encoded spiking network rather than a universal drop-in descriptor.
      \end{block}

    \column{0.48\textwidth}
      \begin{block}{Why this comparison matters}
        \small
        Our current phase focuses on \textbf{descriptor exploration first}: before adding CLAHE, sequence matching, or temporal filtering, we want to know which representation is strongest in our actual setting.
      \end{block}

      \begin{block}{Methods still planned}
        \small
        CLAHE preprocessing, sequence matching, and temporal prediction remain future or next-phase improvements once the descriptor baseline is settled.
      \end{block}
  \end{columns}
\end{frame}

\begin{frame}{6. Why GardensPoint Is Still Our Main Benchmark}
  \begin{columns}[T,totalwidth=\textwidth]
    \column{0.54\textwidth}
      \begin{block}{Why we keep it}
        \small
        GardensPoint is still the right primary benchmark for this project because it directly matches the task we care about: \textbf{day-to-night place recognition}. It gives us a clean, controlled test before moving to the noisier campus setting.
      \end{block}

      \begin{block}{What we learn from it}
        \small
        \begin{itemize}
          \item whether a descriptor can handle a strong day-night appearance gap
          \item whether the correct place is ranked first or only appears later in the list
          \item whether a strong result is consistent across many query frames
        \end{itemize}
      \end{block}

      \begin{block}{How we interpret it}
        \small
        We treat GardensPoint as the \textbf{controlled benchmark}, then use the campus dataset as the \textbf{transfer test} for our own environment.
      \end{block}

\begin{frame}{8. What The Strict Campus Results Mean}
  \begin{columns}[T,totalwidth=\textwidth]
    \column{0.44\textwidth}
      \includegraphics[width=\linewidth,height=0.56\textheight,keepaspectratio]{../../output_images/runs/campus_strict/0004_campus_strict_salad_20260424_150007/pr_curve.png}

      \vspace{0.4em}
      \begin{block}{Key observation}
        \small
        The campus setting is much harsher than GardensPoint because it mixes day-night change with viewpoint change, limited map coverage, and many hard no-match cases.
      \end{block}

    \column{0.52\textwidth}
      \begin{block}{Interpretation}
        \small
        \begin{itemize}
          \item \textbf{SelaVPR++} gives the best top-1 retrieval under the strict protocol.
          \item \textbf{SALAD} stays consistently strong and reaches perfect R@5 and R@10.
          \item \textbf{CosPlace} remains a strong practical baseline.
          \item \textbf{VPRTempo} is not competitive in this transfer setup.
        \end{itemize}
      \end{block}

      \begin{block}{Main lesson}
        \small
        Strong modern descriptors clearly help, but descriptor quality alone does not fully solve rejection and ambiguity in a small real campus deployment.
      \end{block}
  \end{columns}
\end{frame}

\begin{frame}{10. Main Findings}
  \begin{enumerate}
    \item Our hypothesis is supported: descriptor choice strongly affects nocturnal VPR performance.
    \item GardensPoint remains the right primary benchmark because it directly matches the day-to-night problem.
    \item The best descriptors we tested are now \textbf{SelaVPR++ and SALAD}, with CosPlace still a strong practical baseline.
    \item The strict campus dataset is much harder than GardensPoint and exposes the remaining gap between benchmark success and deployment success.
    \item VPRTempo did \textbf{not} transfer well here, mainly because the official checkpoint is a Nordland demo model rather than a universal descriptor.
    \item The live system is already in place, so the next phase is to connect the strongest descriptors and lightweight temporal improvements to a robust demo.
  \end{enumerate}
\end{frame}

\begin{frame}{11. Next Steps}
  \begin{block}{What we would do next}
    \small
    \begin{itemize}
      \item integrate \textbf{SALAD} and \textbf{SelaVPR++} into the live path as the strongest current descriptors
      \item test lightweight improvements such as \textbf{CLAHE} and \textbf{sequence matching}
      \item improve \textbf{no-match rejection} for campus deployment
      \item compare accuracy against runtime and deployment cost for a practical robot demo
    \end{itemize}
  \end{block}

  \vspace{0.6em}
  \begin{block}{Demo message}

  \end{block}
